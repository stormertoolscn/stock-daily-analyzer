# LHB Stock Analyzer Logo

国际金融气质图标（蓝渐变 / 圆角 squircle / 轻玻璃景深），避开国内券商常见大红风格。

## 文件

| 文件 | 说明 |
|------|------|
| `lhb-app-icon-1024.png` | 主视觉 1024×1024 |
| `LHBStockAnalyzer.ico` | Windows 多尺寸 ICO（16–256） |
| `png/icon-*.png` | 分尺寸 PNG：16 / 24 / 32 / 48 / 64 / 128 / 256 |
| `build_ico.py` | 从 1024 PNG 重新生成 ICO/PNG |

## 重新生成

```bat
backend\.venv\Scripts\python.exe branding\logo\build_ico.py
```
